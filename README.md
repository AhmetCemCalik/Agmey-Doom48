# Overview
A classic 2048 with a custom UI. Really not much to talk about. Built on M chip ARM64 arch.

A very thorough report about the project is present in the project repo, since this was originally a school project. I have decided not to gitignore it, if anyone wants detailed knowledge about the game.

## Running & Compilation

Game can be played with running these commands from the project root in order.
```bash
mkdir build
cd build
cmake ..
cmake --build .
./2048
```
